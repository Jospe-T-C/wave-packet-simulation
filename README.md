# Wave Packet Simulation

An interactive web application designed to visualize and explore
Gaussian wave packets, wave propagation and the principle of
superposition through dynamic simulations.

## Project Overview

This project demonstrates the behaviour of wave packets through
interactive visualizations, helping users understand wave formation,
interference and superposition.

## Features

- Gaussian wave packet simulation
- Visualization of wave propagation
- Superposition of multiple waves
- Interactive simulation interface
- Theoretical explanations and working demonstrations

## Project Structure

- `app.py` – Application entry point
- `main_app.py` – Main application interface
- `wave_packet_core.py` – Core wave simulation logic
- `pages/` – Additional application pages

## Technologies Used

- Python
- Streamlit
- Numerical computation
- Interactive data visualization
